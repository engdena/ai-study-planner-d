# StudyFlow AI

Build a full web app called “AI Study Planner for University Students”. 
Do everything from scratch so the app is ready to use immediately.




Requirements:
1. UI/UX
   - Clean, modern, minimal, premium
   - Looks like a real AI startup product
   - Clear hierarchy and spacing
   - Responsive on desktop and mobile




2. Pages / Sections
   - Hero: Title + Subtitle + CTA button
   - Problem: Short explanation + visual illustration
   - Solution: Explain how the planner works + step visuals
   - How it works: 3 steps (Input → Logic → Output)
   - Features: 3–5 main features
   - Who it’s for: University students / self-learners
   - Final CTA: Strong call-to-action button




3. Google Sheet Integration
   - Embed this Google Sheet for live interactive planning: https://docs.google.com/spreadsheets/d/1koW4a1BgcIWwt_eoqJxw35FA9rzt0hP8jCmTDZrGccg/edit?usp=sharing
   - Include “Open Planner” button that opens the Google Sheet in a new tab
   - Ensure users can interact with the planner directly from the site




4. Content
   - Write all copy (headlines, subtext, CTAs)
   - Generate visuals / diagrams to explain the idea
   - No placeholder images




5. Style & Tone
   - Minimal, professional, academic
   - Neutral colors with ONE accent color
   - Subtle animations for engagement
   - Avoid generic templates, crypto, portfolio vibes




Rules:
- Do NOT ask me questions
- Do NOT leave placeholders
- Make all design and content decisions yourself
- Deliver a ready-to-publish app. I only want to click “Publish”.
